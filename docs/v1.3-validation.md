# v1.3 real-research execution validation

## Scope

New standard-library modules:
- `research_cycle.py`: public Crossref/ACL metadata lookup, official ACL PDF text extraction, author-stated limitation *candidate* mining, paper-level citation packet/BibTeX, bounded supervisor decision receipts and SciFact support/refute polarity checks.
- `retrieval_benchmark.py`: actual BEIR-format BM25 title-weight comparison with all per-query metrics, paired-query exploratory intervals, source hashes and measurement-fit boundary.
- `fetch_beir.py`: official SciFact download (source pinned to UKP/BEIR, published MD5), safe ZIP extraction and source manifest.
- `tests/live_real_research_case.py`: network-enabled, actual public source and full 300-query BEIR test; CI attaches actual results.

## Observed local pre-release checks — 2026-10-22

- Local new-module suite: **60 tests, 59 passed and 1 skipped**. The skipped test requires the existing Atlas v1.2 `atlas.py`, which is not copied into this partial local patch. Its test is **required on the complete GitHub checkout** and must pass before any main-branch update.
- Bytecode compilation succeeds for all new Python sources.
- Real Hsieh 2024 PDF checked against ACL original: four distinct limitations; the first local fixture missed one. The original three-lead output is preserved in the project's `history` folder, corrected four-lead batch regenerated and tests updated.
- Real published SciFact examples distinguish `SUPPORT`, `CONTRADICT` and unannotated cited documents. False support assertion is detected.
- Bounded Supervisor decisions: universal method hypothesis PIVOT after contrary work, narrowly scoped follow-up REPAIR_MEASUREMENT because actual answering/latency data remain unverified.
- One documented SciFact retrieval query gives n=1. The system refuses to calculate an unjustified confidence interval or claim it establishes general effectiveness.

## Live CI acceptance gates

The feature branch will not be merged to main unless ALL gates are satisfied:
1. Existing + new Python tests on 3.10, 3.12, 3.13, including one `export_atlas_batch`→**actual Atlas init/upsert/check** integration case.
2. Exact remote snapshot downloads UKP official SciFact ZIP and validates published MD5 before unzipping, then verifies **5,183 corpus docs and 300 labeled test queries**; evaluates all with two preselected lexical ranking variants, retaining 300 rows and bootstrap uncertainty estimates. Dataset qrels support retrieval metrics **only**.
3. ACL original article metadata and PDF are fetched live; DOI, title, page count, PDF SHA256 and section limitation candidates are preserved. Later conflicting paper's identity is verified, without certifying gap/new idea by mere presence.
4. Result files, source SHA hashes, benchmark metrics, negative/failed runs and status are available as a GitHub Actions artifact.
5. README, Skill protocol, source attribution and final test records describe exactly what executed, and the GitHub Actions run is marked success on the exact tree to merge.

If any gate fails, keep feature branch separate, inspect logs, repair code/data assumptions, repeat. Real-world effectiveness of automated novel research discovery and long-context generation is still an open validation task rather than an inferred accomplishment.

## Additional pre-push defect repairs (2026-10-23)

- **Citation access boundary:** previously a user-supplied text excerpt could be labeled `fulltext` via CLI. Added read-depth checks so `fulltext` is reserved for verified PDF/full-text extraction, with a positive and a negative regression.
- **Data evidence validity:** matching SHA256 hashes alone could not establish that the BEIR relevance labels referenced real documents. Added actual qrel-ID/positive-label parsing in `validate_data_contract`, plus a regression using hash-correct but invalid qrels.
- **Independent retrieval-metric audit:** retained all top-k document IDs for each query and added independent reference calculations of Recall, MRR and nDCG over the 300 real official test queries. This catches a shared computation mistake instead of validating only program output against itself.
- **Test fixture assumption:** initially the local 1-query SciFact smoke expected 3 ranked hits from 3 documents, although sparse BM25 may score only 2. Updated the regression to accept fewer than k, preserving honest short ranks. The failed test and correction were inspected locally.
- Local 61-test suite: **60 passed, 1 skipped** pending the full Atlas checkout; new negative checks are included. Full real dataset and PDF live test require CI network execution, and are not yet declared passed.


- **Bibliography provenance:** original exported ACL 2024 proceedings entry was erroneously `@article`; preserved the original in `history/hsieh_bib_initial_article.bib` and regenerated corrected `@inproceedings` with publisher-recorded booktitle.
