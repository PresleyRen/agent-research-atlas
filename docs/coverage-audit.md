# Coverage, complements and conflict decisions / 覆盖与互补审计

Audit: **2026-10-23 · v1.3.0**. **81 sources · 312 features · 32 capabilities · 32 conflict contracts**.

## Scope and status

每个列出的来源特色均映射到采用状态、能力、互补来源、剩余边界与补法。来源读取细节见 [SOURCES](../SOURCES.md)；Supervisor 的完整文本审查、冲突依据与改编范围见 [专门说明](supervisor-source-audit.md)；v1.2 导师闭环新增来源见 [supervision source audit](supervision-source-audit.md)。已执行的行为见 [验证总表](validation.md)、[v1.3 真实论文与 SciFact 端到端验证](v1.3-validation.md) 和 [Supervisor任务记录](supervisor-validation.md)。

| Status | Features | Meaning |
|---|---:|---|
| `implemented` | 11 | Bundled deterministic behavior; specific tests define its guarantees. |
| `protocol` | 203 | Host-executed research instructions, with explicit evidence/decision contracts. |
| `optional` | 49 | Context-specific methods or external tools are selectable; their complete workflow is not implemented or validated here, and external services remain unconnected. |
| `reference` | 8 | Design/background inspiration, not a shipped implementation. |
| `deferred` | 6 | Explicit gap with a remedy; not complete. |
| `rejected` | 35 | Rule intentionally not inherited; keep its useful context and conflict rationale. |

特征数量不是测试通过数量；多个来源可以对应同一个能力。`protocol` 表示本项目提供执行流程；实际研究和语义质量需在相应项目中检查。旧的对照任务与来源审查提案保留原版本边界。
