# Real-source test material provenance

- Hsieh et al. (ACL Findings 2024) original PDF p. 9, Limitation section: https://aclanthology.org/2024.findings-acl.890.pdf DOI 10.18653/v1/2024.findings-acl.890. The short excerpt is quoted from that section, where the authors identify O(K) extra forward passes, potentially beneficial bias, and unknown root causes. It is an excerpt fixture, **not** a claim the entire source was copied or parsed by this test.
- Cuconasu et al. (EMNLP 2025) original PDF p.1: https://aclanthology.org/2025.emnlp-main.1422.pdf DOI 10.18653/v1/2025.emnlp-main.1422. Extracted short contextual statements and abstract finding (not a claim of independent replication).
- SciFact official documentation example claim #123 and its evidence document 4883040 (negative relation): https://github.com/allenai/scifact/blob/master/doc/data.md. The corpus test contains the original evidence sentences, a documentation example doc 4983, and a short publication-based RAG passage. The text for 4883040 is a small excerpt; the third passage is paraphrased. This is a **real-source smoke test**, not the complete SciFact benchmark. Only 1 annotated query is represented and inferential performance claims are prohibited.
- Full BEIR SciFact benchmark can instead be downloaded and checksum-validated with scripts/fetch_beir.py using https://public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/scifact.zip and BEIR's published MD5 5f7d1de60b170fc8027bb7898e2efca1. The source includes 5,183 corpus docs and 300 test claims. Network availability and actual execution are separate checks.
