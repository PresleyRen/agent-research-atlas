# 最小判别方案：先检验信息能否被区分

2026-10-20 / v1。**仅设计，未冻结、未执行。SYNTHETIC 教学项目。**

本轮选择 **M0：恢复证据链并审查可识别性**。只有 M0 通过且后续执行获授权，才进入 **M1：配对四格动作诊断**。当前并没有可用原始案例、已审核数据集或研究运行预算。[S04，全文](../docs/resources.md)

## M0：最先做什么，以及它能判别什么

问题是：“开发笔记中的两个解释，能否由真实输入和可核对标签区别；这种区别在路由时可见吗？”它先排除把猜测、标注歧义、缺元数据误写成路由研究点的风险。

### 输入与记录要求

下一轮先恢复一个具有完整出处的文档家族及对应问题链；无法恢复则停在缺口登记。一个家族是操作化起点，不是统计样本量承诺。已有25条描述的数量、单人来源及选题曝光必须继续记录；本轮没有这些逐例材料，不能预填标签。[S03](../docs/observations.md)、[S04](../docs/resources.md)

每个案例保留下列字段；空白使用 `unknown`，不猜测。

| 字段组 | 内容 | 谁可见 |
|---|---|---|
| 身份与依赖 | `case_id`、`family_id`、原文路径/哈希、语料快照、原始/构造、曾被谁看过 | 记录人员；对路由器隐藏可泄漏结局的ID含义 |
| 决策输入 | 原问题、允许的对话上下文、当时可见片段、版本/适用期/出处、当时已有轨迹 | 路由器 |
| 意图真值来源 | 用户声明或可信任务规格、目标版本/日期及其依据；无法确定时保留集合或未知 | 评价器；只有合法澄清答复可向策略披露其内容 |
| 证据真值来源 | 完整版本文档与有效性依据、支持答案的内容位置、语料是否含所需证据 | 评价器；策略只见动作接口实际返回的部分 |
| 行动接口 | 一次澄清可返回什么、一次检索可访问哪个语料快照/过滤条件、直接回答允许什么形式 | 各策略相同且事前公开 |
| 人工判定 | 目标是否唯一、适用性是否能判、缺口是否可由某动作补齐、可接受结果集合、分歧理由 | 评价器；不能把“应澄清”直接定义为成功真值 |

先让两位整理者分别在**遮住隐藏真值的决策包**中标注可观测信号，再核对完整出处包。当前没有确认可用的标注人，因此这是待满足条件。保留原始判定与分歧；同一人重标只用于自查，不能冒充独立标注。

### 最低结构覆盖与边界

用同一文档家族建立或找到下表四种情形；构造变体必须标 `synthetic` 并保留配对关系。四格是因素组合的最低覆盖，不代表四个独立样本，也不是效应检出的样本量。目标未知时，第二列的状态只能由评价器按隐藏目标判定，不能直接作为候选输入。

| 目标版本是否明确 | 现有证据对目标是否适用 | 待检验的动作差异 | 单步预算的边界 |
|---|---|---|---|
| 明确 | 适用且足以回答 | 直接回答可能已足够；问/查有额外代价 | 不应靠强制追加动作制造难题。 |
| 明确 | 不适用或缺关键证据 | 一次定向检索可能补证据；再问同一版本不一定有效 | 若语料根本缺证据，检索也不能成功。 |
| 不明确 | 对某些合理目标适用 | 澄清可能消除目标缺口；检索不能自动知道用户意图 | 若所有合理目标答案相同或条件式回答满足需求，也可能无需澄清。 |
| 不明确 | 适用性不足/按隐藏目标不适用 | 可能需要澄清后再检索 | 一步可能无法完成；保留两种缺口，不能强给任一路由成功标签。 |

另外必须保留“用户确实要旧版本”“所谓当前指部署版本而非最新发布”“证据不在语料”“无法核实适用期”这些边界。它们防止把时间戳最大值、版本号是否出现等捷径循环定义成正确答案。

### M0 的继续、转向与停止

| 实际观察 | 决定 |
|---|---|
| 能恢复完整出处，至少出现两个单缺口类型；遮罩后仍有合法信号区分动作，并能保留分歧 | 可进入M1设计核实；这仅支持“值得做判别”，不支持方法有效。 |
| 完整信息下可分，遮罩后不可分 | 将C1收窄为可观测性/信息获取问题；禁止用隐藏状态路由成绩宣传部署效果。 |
| 两位整理者不能稳定确定目标或适用性，或标签依赖对最终方法的偏好 | 先修任务定义/元数据/真值来源；保留争议案例。 |
| 恢复不了原始链条、数据权利未核实或资源授权仍不允许 | 停止负载；保留缺口与候选，不写反驳结论。 |
| 简单版本匹配与固定澄清已解释全部区别 | 保留诊断价值；优先简单策略，暂不发展复杂路由。 |

## M1：M0通过后的最小动作比较

### 目标、比较与单位

目标假设是C1：**补用户目标的信息与补证据的信息，在单缺口场景具有不同的作用方向。** 最强替代是统一保守策略/简单版本规则、通用新增文本、成本差异或标签泄漏足以解释所有变化。

每个文档家族中的四变体在所有策略上配对。家族、原任务和用户来源是依赖单位；多个变体、同一案例的多次采样及多种seed不增加独立家族数。起步诊断可以用人工可核对的确定性CPU规则，不要求生成模型。若以后要声称真实任务表现，另需未参与选题的任务/家族、真实实现和相应样本精度设计。

| 策略 | 定义/作用 |
|---|---|
| B0 直接回答/直接提交信息包 | 不追加动作；保留带版本条件的回答作为允许的简单替代。 |
| B1 固定问版本 | 每次仅问一次目标版本/适用日期；答复只含用户本来知道的意图信息，不能顺带给标准答案。 |
| B2 固定再检索 | 每次在同一语料快照检索一次；有明确版本时可据此过滤，目标不明时只能使用当前可见请求，不能偷用隐藏版本。 |
| B3 强简单规则 | 用明确的版本匹配、可见支持证据和必要时的固定提问；规则/阈值在看评价结果前固定。 |
| C1 可见信息来源策略 | 按方法卡判断缺目标、缺证据或不可判定；第一版可与B3重合。若重合，只报告同一规则及机制诊断，不伪造新方法差异。 |
| O 理想状态诊断 | 仅为诊断上界，向策略提供隐藏目标/适用性类别；单独列出，与部署策略严格区分。 |

固定初始片段、语料版本、允许的对话、可查询信息、输出形式、返回条目/文本上限和比较选择机会。一个澄清动作与一个检索动作**不等于相同自然成本**：分别报告提问次数、答复长度、检索次数/返回长度、处理耗时与失败；若需要效率论点，应在未来用实际测量确定成本约束，不能本轮凭空给出等成本结论。

### 指标与判别逻辑

首轮主观察是**动作后目标绑定和有效证据缺口是否消除**，按四格分别给出配对差异。人工真值需依据任务/文档，不按路由名称评分。过程记录保留目标绑定、支持证据ID、仍未解决的缺口及每类成本。有真实且核实的生成器后，才另评任务正确性、证据支持和适当未回答；信息包完成率不能更名为问答准确率。

主要判别是两个单缺口切片中“澄清减检索”的收益方向是否不同。平均总分会掩盖这种交互，不能单独决定机制。最小诊断按家族展示全部配对结果、失败和反例；未来确认分析在数据规模和依赖结构已知后，事前确定最小有用效应、区间方法与样本依据。不指定无依据的万能样本数、效应量或seed数，也不以不显著宣称等效。

需要检验的控制包括：目标明确且证据充分的无缺口对照；澄清答复中的相关版本信息与等长度无关补充；有效新证据与重复旧证据；同义表述而版本约束不变。控制优先针对尚能改变判断的竞争解释，不能无限堆实验。

### 三向结局与失败分支

| 结局 | 可允许的表述与下一步 |
|---|---|
| 单缺口切片出现预测的动作交互，可见信号策略也有对应变化，且简单基线和信息/成本差异被合理比较 | 支持该数据/规则设定下的局部信息来源解释；仍需真实近邻核验和新家族检验。 |
| 只有理想状态诊断有效，或同样收益全部由简单版本规则/通用信息增量解释 | 缩窄C1或停止复杂方法方向；保留上界、简单基线与反例。 |
| 合法可见策略在适当对照与精度下不呈现预测交互 | 挑战当前C1表述；检查前提后决定修订或保留负结果，不能换指标掩盖。 |
| 标签不可靠、双方缺口不能一步解决、语料无证据、区间过宽、实现不符或执行失败 | 无法判断/运行无效，具体说明原因；不归成有效反证。 |
