# 修订版：未来分析计划的区间决策规则

版本：v1；日期：2026-10-21。此文本修订 `old-rule.md` 的解释规则，原稿保留；**此处没有实测结论、实验执行记录或正式冻结声明**。

## 可直接纳入计划的文本

> 我们定义 Δ = baseline loss − candidate loss，正值表示候选损失较低。预定具有实际意义的优越性为严格的 Δ > δ，δ = 0.02。对依照适用设计计算的闭区间 [L, U]，我们以区间相对 0 和 δ 的位置解释效应方向与实际意义，保持这两项判断分开。
>
> **继续分支：** 若 L > δ，整个区间严格高于预定门槛，支持当前比较范围内的实际优越性。随后按原计划做稳健性或独立检验；这一分支本身不确立机制、因果或普遍适用性。
>
> **收窄分支：** 若 U < δ，整个区间低于预定门槛，挑战当前版本的实际优越性预测。若同时 L > 0，允许较小的正向改善；若同时 U < 0，支持候选损失更高的不利方向。若区间含 0，则正负方向仍可能无法区分。不得将低于实际门槛直接写成“无效”“等效”或“机制已被普遍否定”。
>
> **门槛或边界未决分支：** 若 L ≤ δ ≤ U，不宣布严格实际优越性成立。L < δ < U 表示区间跨越门槛；L = δ < U 表示区间触及门槛，仍允许恰等于 δ，因此不满足 L > δ 的继续标准。触界情形保留其精确位置，不统一描述为“跨越”。
>
> 资源动作单独决定。未决分支不自动增加样本、种子、模型运行或费用。未来执行前，应说明独立实验单位、配对或聚类依赖、区间方法和水平、可达到的精度、追加信息的决策价值、资源上限，以及查看和停止规则。只有这些条件支持追加时，才实施预先安排的进一步评估；否则记录未决并停止或暂缓。不因结果不利而降低 δ，也不反复追加到结论有利为止。任何目标、方法或资源策略的修改保留版本与理由，并说明是在何时、看过哪些结果后作出的。

该三分支采用 Skill 的保守边界政策。为避免误读未列入 A–E 的未来情景，补充：**若 U = δ 且 L ≤ U，区间内没有严格大于 δ 的值；不得声称该区间支持严格优越性，也不得把这个触界情景写成“存在高于门槛的区间值”。** 本规则将它记为边界并明确不通过继续标准；是否把它另列为“不达标”行动标签，应在实际分析前另行写明。数学上的端点位置不会因行动标签而改变。

## 使用时的三个限定

1. **边界按原始数值判断。** 本演练把 `scenarios.json` 的数值当作给定的精确端点；E 的 L = 0.02 不能被四舍五入或改用 ≥ 变成通过。未来报告应保存未舍入端点，并预先确定比较精度。
2. **区间判决只针对声明范围。** 本项目假定区间计算适用，本轮没有验证算法、独立性、比较有效性或因果识别。实际研究仍须具备相应依据；几何位置本身不能提供这些依据。
3. **不同目标使用各自规则。** 本文处理严格实际优越性。等效、非劣、机制及因果主张需要各自预定界值或识别证据；不能直接套用此表。
