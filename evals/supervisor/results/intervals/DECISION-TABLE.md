# 路由研究：区间决策演练

**这是未来分析计划的假设情景；没有运行实验，也没有获得实测结果。** 定义 Δ = baseline loss − candidate loss，正值表示候选损失较低；预定实际优越性要求严格的 Δ > δ，δ = 0.02。以下仅在项目已给定的“区间方法适用”前提下，解释闭区间 [L, U] 的位置。[P1][P3]

## 简短决策表

表中“支持”“挑战”“下一步”均表示：**若将来有效评估得到这一情景，预先采用的解释与动作**。

| 情景与区间 | 支持什么结论 | 不能据此推出什么 | 预定决策与下一步 |
|---|---|---|---|
| **A：[0.03, 0.05]**；L > 0.02 | 整个区间严格高于实际门槛，支持该比较范围内的预定实际优越性。 | 不能因为“排除 δ”就挑战该预测；也不能宣布机制、因果关系或跨任务普遍优势已成立。 | **继续**：进入预先安排的稳健性或独立检验，保留原门槛及比较范围。 |
| **B：[0.005, 0.015]**；0 < L ≤ U < 0.02 | 支持较小的正向改善，同时挑战“改善严格超过 0.02”的预测。 | 不支持达到预定实际门槛；不能说完全没有改善、两者等效或整个机制无效。 | **收窄**：保留小幅改善的解释，限制当前实际优越性主张；若改方法或研究目标，另立前瞻版本。 |
| **C：[0.01, 0.035]**；0 < L < 0.02 < U | 支持正向改善；是否超过实际门槛仍无法区分。 | 不能确认或排除实际优越性；不能把门槛未决写成“无改善”。 | **不确定**：先判断进一步缩小不确定性是否值得；只有预定设计与预算支持时，才追加独立信息。 |
| **D：[−0.04, −0.01]**；U < 0 | 区间整体为负，支持候选损失较高的不利方向；同时挑战正向改善及实际优越性预测。 | 不能扩大成所有设置、所有实现下的机制失效，也不能仅凭区间确立因果解释。 | **收窄／修订当前预测**：未来若实际出现，先按原计划核查运行与比较有效性，再处理该版本的不利结果。 |
| **E：[0.02, 0.05]**；L = δ < U | 区间整体为正，允许改善恰等于门槛或大于门槛；严格实际优越性仍未确立。 | 不能用 L ≥ δ 替代 L > δ。它触及门槛，区间内没有低于门槛的值；不能误写为已支持低于门槛。 | **不确定，边界情景**：保留严格规则；如需进一步评估，按与 C 相同的条件决定资源。 |

上述判断由端点与 0、δ 的位置直接推出；规则依据见 [S1]。这些区间没有给出类型、置信水平或后验概率，故本表不添加“95%”“显著”“证明”等描述，也不把损失单位改写成百分比或百分点。

## 旧草案的两处修订

原文件 [old-rule.md](old-rule.md) 保留不变。[P2]

1. **“排除 δ 就挑战优越性预测”缺少方向。** A 完全高于 δ，应支持预定目标；B、D 完全低于 δ，才挑战该目标。必须分别检查 L > δ 与 U < δ。
2. **“含 δ 时增加资源”不能作为自动动作。** C、E 首先归为门槛未决；增加信息是否有用，取决于具体设计、可达到的精度、研究价值与预算。应事先规定查看和停止规则，不追加到得到有利结论为止。[S1][S2]
