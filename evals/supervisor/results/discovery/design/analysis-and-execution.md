# 分析计划、执行路径与停止条件

版本 design-v1.1，2026-10-21。当前只完成设计/文件审查；无模型运行、无新结果、无科学实验 freeze。旧调试数字已经读过，因此基于旧家族的新诊断只能称 exploratory。v1.1 根据协调者协议复核明确区间相对正向 δ 的方向；旧字节保存在 `../worklog/analysis-before-interval-review.md`。

## 1. 待检验假设及最强反解释

H1（`hyp-information-source-value`）：当正确答案取决于未表明的用户目标，且初始文档已充分、合法可访问记录中也没有该目标时，有效目标澄清相对追加检索应更能降低任务损失；当目标已确定而证据可检索但缺失时，补检索应具有更直接的信息收益。H1 只预测这种限定条件下的诊断模式，不声称追问普遍有净效用。

H2（`hyp-explicit-version-rule`）：对版本信息明确且可解析的任务，确定性过滤可能已消除大部分版本选择错误；若如此，不值得为该子问题单独训练门控。这里“足够”需由实际质量容忍度/成本界值定义，不能用“不显著”推导等效。

最强替代解释是：分层定义已将答案写入标签，评分器奖励追问；澄清多出一轮推理/上下文，而非目标信息；初始观察或脚本泄漏了意图；规则基线实现过弱；旧家族重复导致看似泛化；某些切片只因单一家族或文档而出现差异。设计通过多解评分、负对照、信息投影、强基线、族级配对和逐家族展示来检查，不宣称已排除。

## 2. 顺序实验块

| 块 | 产物/最小判别 | 依赖与优先级 | 预算与停止 |
|---|---|---|---|
| E0 数据/接口审计 | 取得原始案例，验证 lineage、O0、隐藏字段；按 rubric 做双人标注和反事实有效性检查 | 最高；当前缺数据是阻断项 | 首先逐家族审核；不做模型调用。关键输入缺失或定义无法裁决即停并修订 |
| E1 固定信息干预 | 在相同 O0/后端下，直接、额外检索、有效澄清、无关回复、无回复条件；给充分证据的诊断上界 | E0 合格后；核心判别 | 次数由真实任务/条件数算；一次信息获取。无关回复同样改善则信息来源解释仍未排除 |
| E2 版本规则判别 | 明确旧/新版的规则过滤 vs 无过滤 vs 候选；文档顺序扰动；解析失败单列 | E0 合格后，可独立于学习模型 | 先规则；目标版本不能从金标读取；有效简单规则已足够则停止新增门控 |
| E3 鲁棒性与成本 | 改写、同答案歧义、用户不知道/拒绝、混合缺口、预算扫描 | 只有 E1/E2 有可解释轨迹才进入 | 预定扫描点一次冻结；不得试到显著才停 |
| E4 学习门控比较 | 同信息/资源与 B4 比较；特征/价值估计消融 | 需要公平规则的稳定残余误差、足够独立家族、实现与算力/费用授权 | 当前 parked；不以 E1 正结果自动授权训练 |

在 E1 中，**理想澄清**使用人工审定问答，测信息可得上界；**策略澄清**由候选提问并可能失败，测实际策略。两者分别报告。若执行后新增“有利子组”，建立新假设版本，使用新数据检验。

## 3. 实验单位和主要估计量

令 g 为独立 family/谱系连通组，i 为组内变体，s 为冻结的切片，a 为条件。对可判的任务，L(g,i,a)=1−S(g,i,a)。先组内平均，再跨组等权平均：

\[
\bar L_{g,a,s}=\frac{1}{n_{g,s}}\sum_{i\in(g,s)}L_{g,i,a},\qquad
\hat L_{a,s}=\frac{1}{G_s}\sum_{g:n_{g,s}>0}\bar L_{g,a,s}.
\]

每个 G_s 和 n(g,s) 都要报告。变体数多的家族不自动得到更高权重。不存在切片的家族不补零；如果只一个家族覆盖某切片，结果只描述该家族，不能估计跨家族推广。

**未来确认性主对比**预定为：在“完整证据、答案敏感、无完整条件回答、用户能给有效回复”的切片上，D_g=平均 L(g,B2 检索)−平均 L(g,B3 有效澄清)。D 为跨家族平均，正值为澄清的质量优势。这是理想信息轨道的机制对比，不能直接解释为生产净效用。策略轨道及其他切片是诊断/次要对比；若要将其升级为共同主要目标，需在新 freeze 明确多重性处理和所需独立样本。

另外报告“补证据切片的检索收益”“同答案歧义中追问是否无价值”“版本规则剩余错误”和“策略澄清失败率”。切片交互 D_s1−D_s2 仅在两切片有足够、可比较组支持时估计；若不同切片是不同家族，不能把家族差异完全归给信息来源。

**不以 gold route accuracy 为主指标**：可能存在多个合格动作。路线匹配仅作为辅助描述，主要判断依最终任务完成与约束/证据、成本。任务响应失败保留于主分母，缺失标签另报；具体规则见 rubric。

## 4. 精度、样本量与不确定性

现有资源笔记只说 8 家族。即使所有文件取得且相互独立，家族数仍太少，不能把 64 改写当独立 Bernoulli 试验来报告窄区间。4/4 探索切分后的 4 个 held-out 家族尤其不能支撑精细子组或真实部署结论。首轮展示每家族配对差、跨家族均值、范围和留一族敏感性；不靠 p 值决定项目去留。

后续若独立家族数足够，使用**配对家族重采样**构造均值差的区间，每次连同所有变体、各方法输出及共同脚本一起重采样；不能逐条变体 bootstrap。报告区间算法、重复数、随机种子、极端/单一切片表现与区间稳定性。少量族时 bootstrap 可能不可靠，只能作为敏感性展示；不要伪称精确覆盖率。

若设计包含真实随机化的处理分配，可以用相应族级随机化检验；并行跑所有算法并不自动产生随机分配，不能没有交换性理由就用置换 p 值。模型随机种子用于测组内运行波动，不能当新任务。确定性规则无需机械重复多种 seed。

正式研究先确定用户可接受的错误损失、追问负担和效应精度。最小有意义差异 δ 由错误代价与新增交互/实现成本推导，**当前未定**；不凭旧调试差额设 δ。若预算固定，报告可达到精度/MDE；若目标精度固定，用探索性族级差的保守方差范围规划新家族数。可将半宽 h 的近似量级写作 G≈(1.96·σ_D/h)^2 做情景估算，但小样本、多切片、混合效应或边界比例时需以最终分析方法另行模拟校准；这不是当前样本量证明。所有假设、δ、h、误差率/功效或精度目标、最大预算在看到确认性结果前登记。

主要对比只设一个；其他诊断报告效应和区间，明确 exploratory，不挑选显著子集。若之后采用多个正式检验，冻结比较集合和校正方法；不能事后把最好的切片改成主要指标。

## 5. 成本与资源预算

当前授权的模型调用数=0、外部请求数=0、付费预算=0；这只是本轮执行边界，不代表未来科学研究成本为零。人工数据审核与标注时间未实测。

若取得原先说明的 64 条，双人逐条初标至少涉及 2×64=128 次标注判断，另加文档核对、家族谱系和争议裁决；这是**条件性工作量计算**，不是已发生记录。若平均每条 t 分钟，初标工时为 128t/60，裁决按实际分歧比例 q 及每条裁决时间 t_d 加 64q·t_d/60。先对开发家族测 t/q/t_d，再决定是否扩集。

执行预算写为：N 个任务实例 × K 个条件 × R 个必要随机重复，得到终止回答运行数；每条件实际检索、澄清、失败重试、token、执行时间另算。64×4=256 只是如果选择 4 条诊断策略的一次探索性终止回答的量级示例，不包含全部 E1/E3 条件、不构成已授权调用，也不是完整运行计划。不能把大量模板变体替代新增独立家族。

真实运行前锁定 N/K/R、模型和版本、token/context 上限、检索 top-k/语料、单任务/总 wall time、重试上限、用户回合、最大总调用与货币费用。以开发集测得的单次分布估算上界；资源未知就保持 blocked。先记录质量及各类成本向量；没有合法价格/用户损失权重时不汇总成虚构“净效益”。

有权重 λ 后可分析 U=−L−λq·Nq−λr·Nr−λt·T−λm·C（各单位和来源要明确），以及对权重、回复概率与错误代价的敏感性。主报告同时给质量—成本 Pareto 前沿，避免单一权重遮蔽取舍。

## 6. 结果到决策表

| 观察条件 | 科学解释 | 下一步 |
|---|---|---|
| 无泄漏、标签可解释，关键切片效应方向符合预测，区间/族级模式稳定 | 初步支持该合成任务中的信息来源诊断，不支持生产泛化 | 查真实最近评测，扩大独立家族并检验外部任务 |
| 有效澄清与无关/空回复同幅改善 | 可能是额外推理或评分偏好，尚不能归给目标信息 | 修对照与评分；停止信息价值优势论点 |
| 规则过滤达到实际可接受质量，门控在成本匹配后无有意义增益 | 简单规则可能足够；不等于所有澄清问题消失 | 保留规则与评测资源，暂缓学习机制 |
| 有效比较中，正向效应 D 的区间下界高于预先定义的正向 δ | 支持该切片、任务与资源范围内达到实际意义的优越性；并未独自排除所有机制替代解释 | 继续检查诊断对照和外部范围；不泛化到生产净收益 |
| D 的区间上界低于正向 δ，但区间没有完全落在 0 以下 | 反对达到该预定最小效果；可能仍有较小正效应，不能笼统反驳信息机制，也不等于等效 | 按已定义投入价值缩小/停止优越性路线；保留较小效果与不确定性，不改 δ 救结论 |
| D 的整个区间低于 0（在预定正向指标与有效比较下） | 支持该设置中检索相对有效澄清更优，挑战该设置的正向比较预测；是否挑战机制还取决于构念、实现与辅助假设 | 保留反向结果并核验竞争解释；按范围修订，不能推出所有澄清均无效 |
| D 的区间包含或跨越 δ，或与 δ 的边界相接 | 对是否达到预定实际效果无法判断；即便区间全大于 0，也未必达到 δ | 依精度/预算停止规则继续或停止，不把显著性当实际价值 |
| 区间很宽、族间异质、标签争议大 | 不足以区分机制和反解释 | 修测量/增加独立族，或按资源停止；不叫等效/反证 |
| 泄漏、家族交叉、评价器未调用、输入/预算不匹配 | 比较无效或实现失真 | 停止该比较并修复；保存记录，重开新实验 ID |
| 用户经常不能回复或成本前沿被其他方法支配 | 理想信息上界可能无实际效用 | 收窄为能力诊断，或停止生产澄清方案 |
| 查新发现既有评测已覆盖问题/协议 | 贡献重叠 | 复用并做复现实证/边界扩展，或停止新 benchmark |

“δ 未定”意味着当前还不能做实践优越性或等效判定，不妨碍现在完成有效性设计。任何 stopped/parked 候选保留原预测、负结果和重启条件。

以上都是未来结果的预定解释规则，没有对应实测区间。区间方法必须符合独立单位与事先声明的覆盖目标；不得从当前 8 家族的资源描述推断它已经提供可靠精度。本次修改仅纠正设计判决逻辑，没有增加数据或升级假设状态。

## 7. 未来实现的方法卡

**输入→操作→输出**：agent-visible JSON→固定输入投影→路由/版本解析→合法工具或澄清环境→同一回答后端→结构化答案及出处→独立 evaluator 读取私有标签→逐项评分→family 聚合。每个箭头保存版本/哈希与 trace。训练（如有）仅读开发分割，学习目标来自开发轨迹，不读评测金标。

**现有组件**：只有资料与本设计；没有实际路由代码、检索实现或评分器。**最简单替代方案**：公开版本规则+直接/条件回答+单次检索。**新组件候选**：只能在残余失败明确后说明收益估计特征、目标函数、训练和推理流程，不现在硬加模型。

实现忠实度审阅必须追踪：reference labels 来源→可见输入构造→route 依赖→环境返回→实际 metric 调用→结果聚合。以隐藏标签扰动不影响输入、错答案确实失败、旧版正确答案不被判错、family 跨分割被拒等检查验证关键风险；这些是软件有效性检查，不是机制支持。

## 8. 冻结、执行与产物要求

当前没有实现/样本，不创建伪可执行 `experiments.py plan`，也不冻结占位命令。`protocol.json` 明确 `execution_ready=false`。下一会话先解决数据与实现，再把本设计转换成真实计划。

未来流程：

1. 保存新实验 ID、研究问题与 rival、主要指标/分母、实验单位、真实 split、所有比较、预算、success/failure/inconclusive 条件及 δ/精度依据。
2. `command.argv` 必须是已检查的真实本地程序；列出确切 `input_files`。immutable 包括 evaluator、metric、held-out labels、split/谱系、文档、提示、预算配置；只有明确声明的候选实现可在探索优化中放 `mutable_input_files`，不允许把评价器改标 mutable。
3. 旧家族诊断 freeze 为 exploratory；新独立评测且符合事前条件才标 prospective。保留方案变更原因与已看结果范围。
4. 在后续明确允许的资源边界内才调用 `run --authorized-local`。当前不执行该命令、不发起后台任务。
5. 保存 stdout/stderr、逐例预测、工具/回复轨迹、失败与超时、前后输入哈希、模型/代码版本、实际成本，再运行 `validate-record`。结构成功不说明科学成立。
6. 将每条结果句链接到 run/字段/计算与范围；结构化 JSON 的数字可用 `audit.py values` 核对；原始 Markdown 调试数字仍需定位阅读，不能伪造 JSON 实测源。
7. 审查结果后才更新 hypothesis 状态，连接真实 `artifact_path`；检查 impact 与 pending reviews，修改受影响方案后记录 review。所有地图变更使用 expected revision。

这份计划允许下一位协作者从具体缺口开始，不需要重复已完成的源文件阅读，也不会误把设计稿当可运行实验。
