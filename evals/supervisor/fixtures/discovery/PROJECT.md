# Intent-aware document agent

This is an explicitly synthetic, offline skill evaluation project. Its local papers and data are fictional fixtures, not real published studies. Do not present them as external literature.

研究目标：找出文档问答 Agent 何时需要追问用户，以及现有评测遗漏了什么。已有思路是把低置信度请求交给一个澄清路由器。我们也考虑建设可复用的评测集。已有 map 和材料在本目录，请接着做。

当前只能进行本地阅读、设计与文件整理；无需执行模型或联系服务。预算与最终数据许可还未确定。希望先得到值得投入的方向、可检验问题与实验方案。
